# Website học từ vựng tiếng Trung H4

## Đăng website miễn phí bằng GitHub Pages
1. Đăng nhập hoặc tạo tài khoản tại https://github.com
2. Bấm dấu + góc trên bên phải → New repository.
3. Đặt tên `hoc-tu-vung-h4`, chọn **Public**, tích **Add a README file** rồi Create repository.
4. Trong repository, bấm **Add file → Upload files**.
5. Kéo thả cả `index.html` và `words.json` vào vùng upload.
6. Bấm **Commit changes**.
7. Vào **Settings → Pages**.
8. Ở phần **Build and deployment**, chọn **Deploy from a branch**.
9. Branch chọn **main**, folder chọn **/(root)** rồi bấm Save.
10. Đợi 1–3 phút, tải lại trang Pages. GitHub sẽ hiện địa chỉ website dạng `https://TEN-TAI-KHOAN.github.io/hoc-tu-vung-h4/`.

Lưu ý:
- Repository Public nghĩa là người có link có thể xem website và dữ liệu từ vựng.
- Tiến độ học được lưu trên trình duyệt/thiết bị hiện tại (localStorage), không tự đồng bộ sang thiết bị khác.
- Phát âm dùng giọng tiếng Trung có sẵn trong trình duyệt/thiết bị; nếu không nghe được, thử Chrome và kiểm tra âm lượng.
